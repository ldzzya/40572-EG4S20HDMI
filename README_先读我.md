## 使用与数码管

使用现有 TF 卡素材测试本版，无需因为 F 格式化卡。正常轮播继续只使用数字 BMP 与对应 WAV；SW1 仍调用 warning.bmp/warning.wav 及独立闪动警告图层，退出恢复原图和音乐位置。此前修复的 warning.bmp 及图层工具保存在 `TF素材修复`、`tools`，本次没有更改素材格式。

从右数第4位：`C`=启动校验，`0`=两轮校验通过，`F`=数据不匹配，`E`=超时。最右3位保留原含义。

左侧2位在成功时显示写/读时序档位。例如 `230111` 表示写档位2、读档位3、校验通过，右侧111保持原含义。档位2是名义位置，0/1提前两/一拍，3/4延后一/两拍。

失败时左侧2位是诊断信息：F显示最佳尝试中错误字数（十六进制，80表示128字），E显示超时的内部阶段。若仍偏色或出现F/E，请记录完整显示，便于判断下一步；不要只看最后的111。

## 修改范围

- `SD/sdram_stream_align.v`：显存流校验与整字对齐。25种读写组合；128字两组互补数据，以64+64写/128读和128写/64+64读交叉检查。只选择全部匹配的档位，失败时等控制器空闲再回原路径。测试区位于三帧RGB24缓存之外。
- `SD/sdram.v`：连接校验模块，将在途命令计入忙状态。
- `SD/frame_read_write.v`：192字读突发、320字显示预留，读补充阈值与写入阈值相接，兼顾扫描不中断与消隐期间写入推进。未增大FIFO。
- `include/global_def.v`：按EM638325要求每64ms完成4096次刷新，49.5MHz下名义间隔773周期。依据：[Etron规格书](https://etron.com/wp-content/uploads/2022/04/EM638325_Rev-3.2.pdf)。
- `top_tf_hdmi_audio.v`：用左侧空闲数码管显示校验细节。

与上一候选版相比，另外107个src文件哈希一致。保留1280×720/60Hz、RGB24图片、48kHz音频、实时菜单、比例适配、音量音柱和V12应急流程；不继承V13～V16。
